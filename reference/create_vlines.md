# Add vertical lines to plot

Add vertical lines to plot

## Usage

``` r
create_vlines(plot, plot_data, vline_vars, vline_day_numbers)
```

## Arguments

- plot:

  A ggplot2 object

- plot_data:

  Data of the plot

- vline_vars:

  A list used to define the label and position of dashed lines in the
  plots

## Value

A ggplot2 object
