# Create/complete a colour palette which maps colours to grading levels.

Create/complete a colour palette which maps colours to grading levels.

## Usage

``` r
fill_palette(grading_vals, user_palette = NULL)
```

## Arguments

- grading_vals:

  `[character(1+)]` vector of grading values/levels.

- user_palette:

  `[character(1+) | NULL]` named character vector mapping colour(s) to
  grading level(s).

## Value

`[character(1+)]` an updated colour palette where colours are mapped to
ALL grading levels.
