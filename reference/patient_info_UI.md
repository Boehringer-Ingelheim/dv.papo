# Create user interface for the patient information shiny module of dv.papo

Create user interface for the patient information shiny module of
dv.papo

## Usage

``` r
patient_info_UI(id)
```

## Arguments

- id:

  A unique ID string to create a namespace. Must match the ID of
  [`patient_info_server()`](https://boehringer-ingelheim.github.io/dv.papo/reference/patient_info_server.md).

## Value

A shiny `uiOutput` element.
