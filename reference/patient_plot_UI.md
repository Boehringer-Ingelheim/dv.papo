# Create user interface for patient plot shiny module of dv.papo

Create user interface for patient plot shiny module of dv.papo

## Usage

``` r
patient_plot_UI(id)
```

## Arguments

- id:

  A unique ID string to create a namespace. Must match the ID of
  [`patient_plot_server()`](https://boehringer-ingelheim.github.io/dv.papo/reference/patient_plot_server.md).

- title:

  character: Title of plot module
