# Convert possibly truncated character(n) 'yyyy-mm-dd' to Date(n) performing optional round up using the level of precision present in the input data

Convert possibly truncated character(n) 'yyyy-mm-dd' to Date(n)
performing optional round up using the level of precision present in the
input data

## Usage

``` r
robust_ymd(data, round_up = FALSE)
```

## Arguments

- data:

  `[character(n)]` Vector of dates
